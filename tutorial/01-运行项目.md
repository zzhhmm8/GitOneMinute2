# 01：运行项目

## Windows + Visual Studio 2022

需要安装 VS2022 的“使用 C++ 的桌面开发”工作负载，包含 MSVC、Windows SDK 和 C++ CMake 工具。只安装 Git 并不能编译 C++。

1. 将压缩包解压到例如 `E:\GitPractice\GitOneMinute`。
2. VS2022 选择“文件 → 打开 → 文件夹”，选择包含 `CMakeLists.txt` 的 GitOneMinute 文件夹。
3. 等待 CMake 配置结束，选择 `GitOneMinute.exe` 为启动项并运行。

也可以打开 **Developer PowerShell for VS 2022**，执行：

```powershell
cd E:\GitPractice\GitOneMinute
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Debug
chcp 65001
.\build\Debug\GitOneMinute.exe
```

这里的 E 盘路径只是示例，需改为实际路径。`chcp 65001` 用来帮助终端正确显示 UTF-8 中文。如果中文仍乱码，使用 Windows Terminal 并选择支持中文的字体。

## Linux / macOS

安装 C++ 编译器和 CMake 后，在项目根目录执行：

```bash
cmake -S . -B build
cmake --build build
./build/GitOneMinute
```
